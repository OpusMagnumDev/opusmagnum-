# Agentes

| Agente | Responsabilidade |
|---|---|
| Hermes | Orquestração e decisões |
| Argos | Pesquisa e verificação de fontes |
| Homerus | Roteiros e narrativa |
| Apollo | Direção criativa e storyboard |
| Vulcanus | Produção e testes técnicos |
| Minerva | Estratégia e avaliação |

Cada entrega deve indicar entradas, resultados, limitações e próximo passo. Não alegar execução sem evidência. Estes protocolos não são agentes autônomos instalados.
