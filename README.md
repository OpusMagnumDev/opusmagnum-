# Opus Magnum

Centro de desenvolvimento de IA, automação, formação e produção audiovisual.

## Princípios
- Começar com ferramentas acessíveis pelo celular.
- Validar resultados antes de automatizar.
- Não armazenar credenciais ou dados pessoais no repositório.

## Estrutura
- `agents/`: protocolos dos agentes.
- `projects/`: projetos e objetivos.
- `automations/`: fluxos de automação.
- `documentation/`: decisões e procedimentos.
- `experiments/`: testes reproduzíveis.

## Estado inicial
Fundação. Agentes são inicialmente protocolos de trabalho, não serviços autônomos.
